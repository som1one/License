ЭНДПОИНТЫ API
--------------

Базовый URL: http://localhost:8000/api

Основные:
   • GET /api/products              - Список продуктов
   • GET /api/license?product=PC    - Генерация (общий)
   • GET /api/license/pycharm       - PyCharm лицензия
   • GET /api/license/idea          - IntelliJ IDEA лицензия

Специфические для продуктов:
   • /api/license/goland            - GoLand
   • /api/license/phpstorm          - PhpStorm
   • /api/license/clion             - CLion
   • /api/license/rider             - Rider
   • /api/license/datagrip          - DataGrip

Загрузки:
   • GET /api/download/ja-netfilter.jar - ja-netfilter.jar

Дополнительно:
   • GET /                         - Корневой эндпоинт

Swagger UI:
   • http://localhost:8000/docs     - Интерактивная документация

ВОЗМОЖНЫЕ ПРОБЛЕМЫ
------------------

1. Сервер не стартует:
   → Проверьте, что Python 3.8+ установлен
   → Установите зависимости
   → Посмотрите логи в консоли

2. Соединение не удается:
   → Убедитесь, что сервер запущен
   → Проверьте firewall
   → Попробуйте перезапустить

3. Плохое качество интернет:
   → Используйте локальный кэш
   → Добавьте таймауты в запросы
